# Social links profile

A responsive social-links profile built with plain HTML and CSS. It uses the supplied Inter font and starter portrait, and follows the project style guide's dark background, lime accent, and light text.

## Run locally

Open `index.html` in a browser, or serve this folder with a static file server. For example, from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Make it yours

- Update the name, location, bio, and social URLs in `index.html`.
- Replace `assets/images/avatar-jessica.jpeg` with your own portrait and update the image path and alt text in `index.html`.
- Adjust the colors, spacing, and responsive styles in `style.css`.
